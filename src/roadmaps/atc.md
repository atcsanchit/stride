## Phase 3 · Mock ladder (days 61–90)
- [ ] Mocks M1–M3 — expect 95–103; classify every dropped mark into a bucket; fix top-2 buckets weekly
- [ ] Mocks M4–M8 — expect 104–110; rehearse the 3-pass algorithm until automatic
- [ ] Final 3 mocks — stable 110–115 with Part A finished ≤55 min
- [ ] Exam-ready gate — 3 consecutive mocks ≥110 and silly-error bucket ≤5 marks
- [ ] No new chapters after day 80 — mocks, error log, formula sheets only

## Exam-day algorithm (rehearse until automatic)
- [ ] Pass 1 (0–80 min) — Part A first (locked before Part B); then Part B banking Layers 1+2 only, ≤60 s/Q, park the rest
- [ ] Pass 2 (80–110 min) — Layer-3 pay-zone; 2-minute cap per question, confidence order, partial-traction first
- [ ] Pass 3 (110–118 min) — guess-fill every blank (no negative marking = free EV) + unit/sign checks on computed answers
- [ ] Speed caps — English 40–50 s/Q · Reasoning 45–60 s (puzzles ≤90 s) · Aptitude 60–75 s · GK ≤20 s · Physics 10/45/90 s by layer · Maths 15/60/120 s by layer
- [ ] Pre-compute ritual — unit/dimensional check before every calculation; it kills half the wrong options without algebra
