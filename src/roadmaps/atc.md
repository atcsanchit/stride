# AAI ATC (Junior Executive) — Exam Prep

## How this course runs
- [ ] Baseline full mock (120 Q / 120 min) — log raw score, attempts, accuracy; open the error log with 4 buckets: concept / speed / silly / time-trap
- [ ] Build the three formula sheets (Maths, Physics, GK static core) — one page each, from the Pattern notes of every class
- [ ] Lock the score architecture — Tech 50–55 + Eng/Reas 31–33 + Apt 13–14 + GK 8–9 = 112–115 target (UR 2025 cutoff: 108)
- [ ] Weekly dashboard watch — aai.aero → Careers → Recruitment Dashboard for the next JE(ATC) advertisement (none open as of Oct 2026; last cycle closed Apr 2026)
- [ ] Fix the weekly calendar — 1 timed sectional alternating Tech / Part A from week 3; full mocks from week 9
- [ ] Weekly Sunday ceremony — Stride class %, heatmap streak, current level, XP earned, next week's main quest
- [ ] Respawn rule — resume, never restart: a failed boss extends the act by 1–2 weeks; the ladder stays

## Maths · Calculus (integration & differentiation)
- [ ] Recite cold: 12 standard integrals + 8 derivative results from the class Pattern notes
- [ ] Drill A: 30 mixed standard-form integrals/derivatives at ≤30 s each
- [ ] Applications: area under curves — y² = 4ax with latus rectum (answer 8a²/3), line–parabola regions
- [ ] The AAI favourite substitution: ∫√(a²−(log x)²)/x dx type → t = log x
- [ ] Trap drill: verify every answer by differentiating back; domain-check any √ before integrating

## Maths · Vectors & 3-D geometry
- [ ] Dot & cross: compute, angle between vectors, projection, perpendicular/parallel conditions
- [ ] Triple products: [a b c] = volume + coplanarity test; a×(b×c) = (a·c)b − (a·b)c
- [ ] PYQ styles: collinear position vectors → find the unknown; parallelogram/triangle area from |a×b|
- [ ] Timed set: 15 vector PYQs at ≤45 s each

## Maths · Probability & counting
- [ ] Addition & multiplication rules; at-least-one trick P = 1 − P(none)
- [ ] With vs without replacement drills; base rates — P(king) = 1/13, two-dice sum 7 = 6/36
- [ ] PYQ set: 10 probability questions at ≤45 s each

## Maths · Trigonometry
- [ ] Recite cold: values table (0–90°), core identities, compound/double/triple angle formulas
- [ ] PYQ style: direct cos(a+b) / sin 2A evaluation with standard angles
- [ ] Timed set: 10 recall questions at ≤30 s each

## Maths · Matrices & determinants
- [ ] 3×3 determinant expansion + properties (row-swap sign flip, |AB| = |A||B|, identical rows → 0)
- [ ] Adjoint & inverse: A(adjA) = |A|I; singular ⇔ |A| = 0 — solve the "find a" PYQ family
- [ ] Systems: Cramer's rule and the three consistency cases

## Maths · Complex numbers, quadratic & coordinate basics
- [ ] Complex numbers: modulus, argument, conjugate properties (z·z̄ = |z|²), powers of i cycle
- [ ] Quadratic equations: discriminant D = b²−4ac, nature of roots, sum/product of roots — the "find k for real roots" PYQ family
- [ ] Straight lines: slope forms, parallel (m₁ = m₂) vs perpendicular (m₁m₂ = −1), point-to-line distance
- [ ] Binomial theorem: general term T(r+1) = C(n,r)·aⁿ⁻ʳ·bʳ, number of terms, middle term

## Maths · Sets, relations & functions
- [ ] Cardinality: two-set and three-set union formulas; Venn word problems
- [ ] De Morgan + subset count (2ⁿ); n(A) from complement chains
- [ ] Relations (reflexive/symmetric/transitive) & function counts (|B|^|A| total, bijections |A|!)

## Maths · Limits, continuity & differential equations
- [ ] Standard limits table + L'Hôpital for 0/0 and ∞/∞
- [ ] Continuity: piecewise unknown-constant problems (LHL = RHL = f(c))
- [ ] DE: variable-separable + linear with integrating factor (solve the dy/dx = y/x family)

## Physics · Units, dimensions & measurement
- [ ] Dimensional check drill — 20 equations judged correct/incorrect in 10 minutes
- [ ] Error propagation: % error adds with powers; least count; the pendulum g-error chain (Δg/g = Δl/l + 2ΔT/T)

## Physics · Mechanics & gravitation
- [ ] Kinematics: v = u + at, v² = u² + 2as, s–t and v–t graph slopes/areas
- [ ] NLM + friction: incline a = g(sinθ − μcosθ), blocks and pulleys
- [ ] Work–energy–power: theorem problems, P = F·v, energy conservation chains
- [ ] Gravitation: g(h) and g(d) variations, escape & orbital velocities, Kepler's third law

## Physics · Electrostatics & capacitance
- [ ] Coulomb + superposition; point-charge fields
- [ ] Gauss law: Φ = q/ε₀ — shell (inside 0, outside kQ/r²), solid sphere (∝ r inside), wire & sheet fields
- [ ] Potential: V = Ed in uniform fields (PYQ: E = 500 V/m, ΔV = 20 V → 4 cm); equipotentials ⊥ E
- [ ] Capacitors: C = ε₀A/d, dielectric κ, series/parallel, energy U = ½CV²

## Physics · Current electricity
- [ ] Series/parallel + R = ρL/A; equivalent-resistance speed drill
- [ ] KVL/KCL: two-loop circuits solved in ≤90 s
- [ ] Cells: emf, internal resistance, terminal V (ε − Ir discharging); power P = I²R

## Physics · Magnetic effects & EMI
- [ ] Field sources: wire μ₀I/2πr, loop centre μ₀I/2R, solenoid B = μ₀nI
- [ ] Forces: F = qvB (r = mv/qB), F = BIL; Fleming left/right-hand rules drilled
- [ ] Faraday & Lenz: ε = −dΦ/dt; motional emf = Blv
- [ ] PYQ set: 15 mixed questions at ≤45 s each

## Physics · Electromagnetic waves
- [ ] Maxwell's unification + displacement current (the recurring "which equation" PYQ)
- [ ] Spectrum ordering with uses; E₀/B₀ = c conversions
- [ ] Intensity drill: I = ½ε₀E₀²c numeric problems

## Physics · Heat & thermodynamics
- [ ] First law ΔU = Q − W; Cv = (f/2)R, Cp = Cv + R, γ = (f+2)/f
- [ ] Processes: W from P–V area; isothermal W = nRT ln(V₂/V₁); adiabatic PV^γ = const
- [ ] Engines & refrigerators: η = 1 − Tc/Th; COP = Tc/(Th − Tc)
- [ ] Kinetic theory: PV = ⅓Nmv²rms, v_rms = √(3RT/M)

## Physics · Optics
- [ ] Mirrors with Cartesian signs: 1/v + 1/u = 1/f, m = −v/u — sign drill first
- [ ] Lenses: 1/v − 1/u = 1/f, m = v/u, power P = 1/f, lenses in contact
- [ ] Refraction: Snell, TIR & critical angle, apparent depth, prism minimum deviation
- [ ] Wave optics: YDSE β = λD/d, bright nλ / dark (2n−1)λ/2, polarisation basics

## Physics · Modern physics
- [ ] Photoelectric: hf = φ + Kmax, stopping potential, threshold frequency; intensity vs frequency roles
- [ ] de Broglie: λ = h/p; electron through V volts → λ = 12.27/√V Å
- [ ] Bohr: Eₙ = −13.6/n² eV, rₙ = 0.529 n² Å, spectral series names
- [ ] Nuclei: BE = Δm × 931.5 MeV; decay law N = N₀e^(−λt), half-life t½ = 0.693/λ

## Physics · Semiconductors & devices
- [ ] p–n junction: barrier potential, forward/reverse behaviour; rectifiers (full-wave output = 2× mains frequency)
- [ ] Special diodes: Zener regulation, LED (λ from E_g), photodiode
- [ ] Logic gates: truth tables + Boolean reduction; transistor β = α/(1−α)
